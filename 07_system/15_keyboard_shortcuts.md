# Bash 快捷键速查表

## 📍 光标移动

| 快捷键 | 功能 | 助记 |
|--------|------|------|
| `Ctrl + A` | 移动到行首 | A = Arrival (到达) |
| `Ctrl + E` | 移动到行尾 | E = End (结束) |
| `Ctrl + F` | 向前移动一个字符 | F = Forward (向前) |
| `Ctrl + B` | 向后移动一个字符 | B = Backward (向后) |
| `Alt + F` | 向前移动一个单词 | F = Forward |
| `Alt + B` | 向后移动一个单词 | B = Backward |
| `Ctrl + XX` | 在行首和当前位置间切换 | X = eXchange (交换) |

## ✏️ 文本编辑

| 快捷键 | 功能 | 助记 |
|--------|------|------|
| `Ctrl + D` | 删除当前字符 | D = Delete (删除) |
| `Ctrl + H` | 删除前一个字符 (退格) | H = Backspace |
| `Alt + D` | 删除当前单词 | D = Delete |
| `Ctrl + W` | 删除前一个单词 | W = Word (单词) |
| `Ctrl + U` | 删除到行首 | U = Up (向上) |
| `Ctrl + K` | 删除到行尾 | K = Kill (删除) |
| `Ctrl + Y` | 粘贴被删除的文本 | Y = Yank (拉回) |
| `Ctrl + T` | 交换当前和前一个字符 | T = Transpose (交换) |
| `Alt + T` | 交换当前和前一个单词 | T = Transpose |
| `Alt + C` | 大写化当前单词 | C = Capitalize (大写) |
| `Alt + U` | 大写化从光标到行尾 | U = Uppercase |
| `Alt + L` | 小写化从光标到行尾 | L = Lowercase |

## 📜 历史命令

| 快捷键 | 功能 | 助记 |
|--------|------|------|
| `Ctrl + P` | 上一条命令 | P = Previous (上一个) |
| `Ctrl + N` | 下一条命令 | N = Next (下一个) |
| `Ctrl + R` | 反向搜索历史 | R = Reverse (反向) |
| `Ctrl + S` | 正向搜索历史 | S = Search (搜索) |
| `Alt + P` | 搜索以当前文本开头的历史 | P = Previous |
| `Alt + N` | 搜索下一条匹配的历史 | N = Next |
| `Ctrl + G` | 退出搜索模式 | G = Give up (放弃) |
| `!$` | 上一条命令的最后一个参数 | |
| `!^` | 上一条命令的第一个参数 | |
| `!*` | 上一条命令的所有参数 | |
| `!!` | 上一条命令 | |

## 🎛️ 控制快捷键

| 快捷键 | 功能 | 助记 |
|--------|------|------|
| `Ctrl + C` | 终止当前命令 | C = Cancel (取消) |
| `Ctrl + Z` | 暂停当前命令 | Z = Zzz (睡眠) |
| `Ctrl + L` | 清屏 | L = Clear (清屏) |
| `Ctrl + O` | 接受建议并显示下一条 | O = OK |
| `Ctrl + X` | 显示可能的快捷键 | X = eXtend (扩展) |
| `Ctrl + V` | 输入下一个字符的字面值 | V = Verbatim (逐字) |
| `Ctrl + Q` | 恢复终端输出 | Q = Quit (退出流控) |
| `Ctrl + S` | 暂停终端输出 | S = Stop (停止流控) |

## 📦 其他实用快捷键

## 💡 实用技巧

### 1. 快速重复命令
```bash
# 使用 !!
sudo !!  # 以 sudo 重复上一条命令

# 使用 !n (n 是历史编号)
!123    # 执行历史编号为 123 的命令
```

### 2. 快速参数引用
```bash
# 使用 !$
vim !$  # 用 vim 打开上一条命令的最后一个参数

# 使用 !^
cp !^ /tmp/  # 复制上一条命令的第一个参数到 /tmp
```

## 🎯 记忆技巧

### 分组记忆
- **A-E**: 行首 - 行尾 (Alphabet 首尾)
- **F-B**: 前后移动 (Forward-Backward)
- **U-K**: 删除 (Up-Kill)
- **P-N**: 历史命令 (Previous-Next)
- **C-Z**: 控制 (Cancel-Sleep)

### 手指位置
- **Ctrl 系列**: 左手小指按 Ctrl，其他手指按字母
- **Alt 系列**: 左手拇指按 Alt，其他手指按字母
