## 🚀 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/hjs2015/shell-notes.git
cd shell-notes
```

### 2. 运行第一个脚本

```bash
chmod +x 00_quickstart/01_hello_world.sh
./00_quickstart/01_hello_world.sh
```

### 3. 开始学习

按照上方学习路径，从 `00_quickstart/` 开始，循序渐进。
