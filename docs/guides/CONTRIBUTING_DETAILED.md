# 📖 详细贡献指南

**快速指南**：[CONTRIBUTING.md](../../CONTRIBUTING.md)

---

## 💻 开发环境设置

1. Fork 仓库
2. 克隆到本地
3. 创建分支
4. 开发和测试
5. 提交更改
6. 创建 Pull Request

## 📝 代码规范

- 脚本命名：语义化，两位数字前缀
- 注释要求：包含功能描述、难度等级、知识点
- 代码风格：清晰的格式，有意义的变量名

## 🔒 安全规范

**禁止提交**：真实 IP、主机名、密码、Token、邮箱

**使用示例值**：IP: 192.168.1.100, 主机名：web-server-01

## 📋 提交规范

格式：`<type>: <subject>`

类型：feat, fix, docs, style, refactor, test, chore

## 🔄 PR 流程

1. 创建 PR
2. 填写描述
3. Code Review
4. 合并后同步
