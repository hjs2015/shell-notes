### 新手路线（0-3 个月）

```
第 1 天：
├── 阅读 README.md（了解仓库）
├── 阅读 LEARNING_PATH.md（制定计划）
└── 运行 00_quickstart/ 脚本（快速开始）

第 2-7 天：
├── 学习 01_basics/（28 个脚本）
├── 参考 CHEATSHEET.md（语法速查）
└── 查看 FAQ.md（解决问题）

第 8-21 天：
```
