# 📝 提交信息指南

## 📋 格式

```
<type>: <subject>
```

## 🎯 Type 类型

- `feat`: 新功能
- `fix`: Bug 修复
- `docs`: 文档更新
- `style`: 代码格式
- `refactor`: 代码重构
- `test`: 测试相关
- `chore`: 构建/工具

## ✍️ 规则

- ✅ 使用祈使句："add" 不是 "added"
- ✅ 首字母小写
- ✅ 无句号
- ✅ 50 字符以内

## 📊 示例

```bash
feat: 添加密码验证器脚本
fix: 修复文件权限检查错误
docs: 更新 README 学习路径
```
