## 🔍 快速查找

### 常用语法
- **变量定义** → `VAR=value`
- **变量引用** → `$VAR` 或 `${VAR}`
- **算术运算** → `$(($a + $b))`
- **条件判断** → `[[ $a -eq $b ]]`
- **字符串比较** → `[[ "$a" == "$b" ]]`
- **文件测试** → `[[ -f file ]]`
- **for 循环** → `for i in {1..10}; do ... done`
- **while 循环** → `while [[ $i -lt 10 ]]; do ... done`
- **函数定义** → `function name() { ... }`
- **数组定义** → `arr=(val1 val2 val3)`

### 特殊变量
- `$0` - 脚本名
- `$1`, `$2` - 位置参数
- `$#` - 参数个数
- `$@` - 所有参数
- `$*` - 所有参数（合并）
- `$?` - 上个命令返回值
- `$$` - 当前进程 ID
