rhel6及前之前的版本，服务启动是sysV,这种管理的特点:
服务是串行启动，如果开机进入5级别要启动100个服务，则会按顺序来启动

# ls /etc/rc.d/rc5.d/	--这里就可以看到大量的服务脚本和其在5级别是否启动，还包括启动顺序信息

S10network	--表示network会启动(S代表start)，10代表一个启动顺序编号
K83named	--表示named不会启动(K代表kill),83代表一个关闭顺序编号



/etc/rc.d/rc0.d/
/etc/rc.d/rc1.d/
/etc/rc.d/rc2.d/
/etc/rc.d/rc3.d/
/etc/rc.d/rc4.d/
/etc/rc.d/rc5.d/
/etc/rc.d/rc6.d/
上面这几个目录分别就代表init0--init6级别的服务启动关闭情况，那么假设我有一个sshd的服务脚本，我需要把这个脚本在上面几个目录里都拷贝一份吗？
答案:不是

它是把服务脚本放一份到/etc/init.d/或/etc/rc.d/init.d/下，(这两个目录是硬链接)，然后在上面0-6级别的目录里只是做软链接而已

rhel7下systemd服务

服务配置文件在/usr/lib/systemd/system/目录下

# cat /usr/lib/systemd/system/sshd.service   --或者使用# systemctl cat sshd.service查看sshd服务的配置

[Unit]
Description=OpenSSH server daemon
Documentation=man:sshd(8) man:sshd_config(5)
After=network.target sshd-keygen.service
Wants=sshd-keygen.service

[Service]
Type=forking
PIDFile=/var/run/sshd.pid
EnvironmentFile=/etc/sysconfig/sshd
ExecStart=/usr/sbin/sshd $OPTIONS
ExecReload=/bin/kill -HUP $MAINPID
KillMode=process
Restart=on-failure
RestartSec=42s

[Install]
WantedBy=multi-user.target

正则表达式  ( Regular Expression，在代码中常简写为regex、regexp或RE)


.	一个字符
..	两个字符
^#	以#号开头
#$	以#号结束
[abc]	包含a或b或c的都匹配
[^abc]	只要出现了abc这三个字母以外的字符就都匹配       --重点
^[abc]  以a开头或以b开头或以c开头
^[^abc] 不以a开头和不以b开头和不以c开头
a+	匹配至少一个或多个a
a*	匹配0或多个a


大写 [[:upper:]]  [A－Z]
小写 [[:lower:]]  [a-z]
字母 [[:alpha:]] [a-Z]	
字母数字 [[:alnum:]]
空格或者制表符 [[:blank:]]
纯数字 [[:digit:]] [0-9]
标点符号 [[:punct:]]

正则表达式，又称正规表示法、常规表示法（英语：Regular Expression，在代码中常简写为regex、regexp或RE），计算机科学的一个概念。正则表达式使用单个字符串来描述、匹配一系列符合某个句法规则的字符串。在很多文本编辑器里，正则表达式通常被用来检索、替换那些符合某个模式的文本。

许多程序设计语言都支持利用正则表达式进行字符串操作。例如，在Perl中就内建了一个功能强大的正则表达式引擎。正则表达式这个概念最初是由Unix中的工具软件（例如sed和grep）普及开的。正则表达式通常缩写成“regex”，单数有regexp、regex，复数有regexps、regexes、regexen。

产生1000个随机的手机号到一个文本，假设手机号前三位有130-139,158,155,186,189这十四种


array=( 130 131 132 133 134 135 136 137 138 139 155 158 186 189 )

for i in `seq 1000`
do
        ran1=$[$RANDOM%14]
        head=${array[$ran1]}
        n1=$[$RANDOM%10]
        n2=$[$RANDOM%10]
        n3=$[$RANDOM%10]
        n4=$[$RANDOM%10]
        n5=$[$RANDOM%10]
        n6=$[$RANDOM%10]
        n7=$[$RANDOM%10]
        n8=$[$RANDOM%10]
        echo "$head$n1$n2$n3$n4$n5$n6$n7$n8" >> phonenum.txt
done
