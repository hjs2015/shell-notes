## 💡 实战项目建议

### 初级项目（第 59-65 天）
1. 系统资源监控脚本（CPU/内存/磁盘）
2. 日志文件清理脚本
3. 用户批量创建脚本
4. 文件备份脚本

### 中级项目（第 66-75 天）
5. 自动化备份系统（带时间戳和轮询）
6. 网站可用性监控（HTTP 状态码检测）
7. 安全扫描脚本（端口/密码强度）
8. Docker 容器管理脚本

### 高级项目（第 76-90 天）
9. 完整部署流水线（Git + 构建 + 部署）
10. Docker Swarm 集群管理
11. Jenkins CI/CD 集成脚本
12. 综合故障排查系统
13. Shell 函数库设计（日志/错误处理/网络检查）

## 🏆 毕业项目

完成一个完整的运维自动化系统，包括：
- 系统监控和告警（邮件/钉钉/飞书）

- 自动化部署（蓝绿部署/滚动更新）
- 故障排查工具集（一键诊断）
- 单元测试框架（保证脚本质量）
